## 🌿 核心理念：為什麼「想通」在焦慮當下沒有用？

當大腦處於急性焦慮或戰逃反應（Fight-or-Flight）時，**交感神經高度興奮，前額葉皮質（理性思維腦）功能被暫時抑制，杏仁核主導恐慌**。此時不斷「告訴自己不要緊張」或「試圖想通」，大腦神經迴路往往無法接收理性訊號。

**真正的解法是由下而上（Bottom-Up）的身體介入**：透過實證的生理反饋動作，直接向腦幹發送「此地安全」的物理神經信號，強制重設自律神經。

## 🧭 三大科學導引動作

### 1. 💨 生理嘆息（Physiological Sigh）
* **科學原理**：源自史丹佛大學神經科學家 Andrew Huberman 實驗室驗證，人體最快在數秒內降低心率與活化副交感神經的自然呼吸模式。
* **操作方式**：連續快速「吸氣兩次（深深吸飽、再補吸一口）」以重新撐開肺泡，接著「深長、緩慢地徹底呼氣」。
* **系統亮點**：內建動態呼吸環狀進度條與頻率節奏視覺輔助。

### 2. 👁️ 全景視野散焦（Panoramic Vision）
* **科學原理**：焦慮會誘發「隧道視野（Tunnel Vision）」，使瞳孔縮放緊繃於單一威脅點。透過故意放寬視野、察覺眼角餘光，能直接抑制腦幹中的警報中樞。
* **操作方式**：凝視前方，不移動眼球，逐漸將注意力擴展至左右兩側的眼角餘光，看見整個房間與環境的輪廓。
* **系統亮點**：全景柔和流動背景與舒緩視距視覺動畫。

### 3. ⚓ 5-4-3-2-1 感官著陸法（5-4-3-2-1 Grounding Technique）
* **科學原理**：認知行為治療（CBT）與創傷輔導常用的身心錨定技巧。透過活化感覺皮質，將注意力從大腦內部的失控災難化思考，拉回當下客觀的現實物理環境。
* **操作方式**：
  * **5** 件看得到的物體
  * **4** 種皮膚感受到的觸覺
  * **3** 種周遭細微的聲音
  * **2** 種環境或衣物的氣味
  * **1** 種口腔留存的滋味
* **系統亮點**：五步驟漸進互動式卡片引導，引導專注填寫與回穩。

## 🛠️ 技術架構

* **前端框架**：原生 HTML5 + 語意化標籤
* **樣式體系**：Tailwind CSS (CDN) + 溫潤護眼大地配色（鼠尾草綠、燕麥奶底、陶土橘）
* **字型字體**：Google Fonts Noto Serif TC（思源宋體）
* **圖標系統**：Font Awesome 6 Pro / Free CDN
* **聲音引擎**：Web Audio API 原生音頻合成器（無須依賴外部大型音檔即可產生舒緩頻率）
* **免伺服器部署**：支援標準靜態 GitHub Pages 託管
